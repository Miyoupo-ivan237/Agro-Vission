🚀 HOW TO START ALL SERVICES
═══════════════════════════════════════════════════════════════

Option 1: Double-click this file
   👉 START_ALL_VISIBLE.ps1

Option 2: Open PowerShell and run:
   👉 powershell -ExecutionPolicy Bypass -File START_ALL_VISIBLE.ps1


📱 HOW TO USE ON YOUR PHONE
═══════════════════════════════════════════════════════════════

Prerequisites:
   ✓ Phone on same WiFi as your PC (192.168.x.x network)
   ✓ Expo Go app installed (iOS App Store or Google Play)

Steps:
   1. Run START_ALL_VISIBLE.ps1 on your PC
   2. Wait for three windows to open (30-60 seconds)
   3. Find the EXPO WINDOW (cyan/blue terminal)
   4. Look for the QR code in the Expo window
   5. Open Expo Go app on your phone
   6. Tap "Scan QR code" at bottom
   7. Point phone camera at the QR code on your PC screen
   8. Wait for app to load (30-45 seconds)
   9. Enjoy Agro-Vission! 🌾

❌ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: Can't see QR code in Expo window
Solution: 
  ✓ Make sure Expo window is fully visible
  ✓ Wait 30-60 seconds for it to load
  ✓ Check that npm is in your PATH
  ✓ Try pressing 'q' and restarting

Problem: Can't connect on phone after scanning
Solution:
  ✓ Make sure phone is on same WiFi
  ✓ Make sure PC IP is 192.168.1.81
  ✓ Check firewall allows port 5000
  ✓ Check that Backend window shows "running"

Problem: Backend shows errors
Solution:
  ✓ Make sure PostgreSQL is running
  ✓ Check that port 5000 is not in use
  ✓ Try restarting with fresh window

Problem: Ollama window shows errors
Solution:
  ✓ Make sure Ollama is installed
  ✓ Make sure "agrovision-agronomist" model exists
  ✓ Check internet for initial model download
